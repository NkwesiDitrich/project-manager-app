# Tasco – Frontend

React (React Router 7, TypeScript, Tailwind, TanStack Query) client for the Tasco project management app.

**Setup and run:** See the [main README](../README.md) in the project root. You need the backend running and a `.env` with `VITE_API_URL` (e.g. `http://localhost:3001/api-v1`).

```bash
npm install
cp .env.example .env   # then set VITE_API_URL
npm run dev
```

- **Build:** `npm run build`
- **Start (production):** `npm start` (serves the built app)
